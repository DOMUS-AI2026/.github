# 🏠 DOMUS AI

### Inteligência para uma residência mais eficiente

O **DOMUS AI** é um projeto acadêmico desenvolvido para a **ExpoTech**, com a proposta de explorar como dados provenientes de sensores e dispositivos conectados podem ser utilizados para compreender o funcionamento de uma residência.

A solução busca transformar **dados brutos em informações úteis**, contribuindo para uma residência mais eficiente, econômica, sustentável e segura.
